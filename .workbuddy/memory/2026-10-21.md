## 01:31 确认根因并修复：`relativeTo` 写了 + `position:[null,null]` 时 null 分量要按 0 驱动

**探针实测（492–548，47 帧 / 31 事件，pan 全 0，anchor==live 全一致）**：

```
[镜头事件] f=528 t=116.893 mode=Player prev=LastPosition posUsed=1 pos=NaN,NaN dur=0.000
           anchor=142.65,-229.44 followStart=141.15,-229.44 carry=141.15,-232.44 resolved=NaN,NaN
[镜头帧]   f=528 out=141.19,-232.44 ball=141.15,-229.44 d=0.04,-3.00 mode=Player followMode=1
[镜头帧]   f=529..536 d 的 Y 一直是 -3.00，到 535 的 `[3,0]` 才被拉回 0
```

**根因**：原生 `ffxCameraPlus.StartEffect` 在「模式重复」守卫之后有一句
`if (movementTypeUsed) { if (IsNaN(vector.x)) vector.x = 0; if (IsNaN(vector.y)) vector.y = 0; }`
—— **写了 `relativeTo` 的事件，null 分量被当成 0 去驱动**。528 是 `relativeTo: Player` + `[null,null]`，
Player 模式下目标就是 0 偏移 = 球本身，原生借此把 518 格自由运镜留下的残差 (0,-3)（≈2 格）清掉。
AES 原来要求「至少一个分量非 NaN」才算写位置，于是把这格整段冻在残差上 → 528~536 画面低 3 个单位。

**修法**（`CameraPreviewDomain.EvaluateChannels`）：`nanAsZero = ModeUsed && HasPosition && (mode != modeBeforeEvent || mode == Global)`，
命中时把 NaN 分量置 0。门槛取「模式真的换了」，因为原生的守卫条件是「模式 == lastUsedMovementType」，
命中时原生整格不驱动位置、NaN 也不归零 —— 这样 Phantigma f396（Tile→Tile `[-4,null]`）的既有校准不受影响。

**影响面**（全谱 1038 条 MoveCamera）：模式切换 + 全 null 位置共 8 处；行为真正改变的是
Player 目标的 5 处（504/507/528/754/801，都是「交回跟随」），479/500/502 的 LastPosition 目标归零与沿用等价。

**部署**：`0 错误 / 49 警告`，`DONE gameRunning=True`（01:31:22），SHA256 `6B95719C10C3BF110BBD7E0482D5E5D41C5037D5F90A45C29F6C87912AB87C8A`。

## 02:09 关键线索：暂停时拉时间轴看到 **UI 重影** → 定位到 ImGui 搬运的残留网格

**用户截图信息**：暂停 + 往下拉时间轴时，UI 出现重影（两套位置不同的人机界面叠在一起）。

**根因（`EditorImGuiBridge.PushToCanvas`）**：
- 旧收尾只清 `for (n = rendererIndex; n < _renderers.Count; n++) Clear()`，即只清"超出末尾"的槽；

  只做 `rendererIndex++; continue;`，那个槽上仍挂着**上一帧的网格**，且因为它的下标小于末尾，
  收尾循环不会碰它 → 旧 UI 留成一层重影。

**改法**：新增 `_rendererTouched` 逐槽标记；每帧开头清零，写网格时置 true；
收尾改成"所有没写过的槽一律 `Clear()`"（不再只看末尾）；跳过分支立刻清掉自己那个槽；
`_rendererTouched` 与 `_renderers` 在创建/销毁处同步维护。

**同轮**：静帧探针改成**只记暂停帧**（播放时的行会把 200 行上限吃光，上次暂停样本只抓到两段）。

## 02:16 重影真因：**HallOfMirrors（镜厅）**——用户实测删掉镜厅事件后重影消失

**用户实测**：删掉前面的镜厅事件后重影没了，但画面仍会闪；把播放头拖回去时，卡时那段的那一帧会**以半透明形式**显现。

**原生实现（全仓只有这三处）**：

```csharp
public void EnableHallOfMirrors(bool homEnabled) {
    this.homEnabled = homEnabled;
    scrCamera.instance.Bgcamstatic.clearFlags = homEnabled ? CameraClearFlags.Depth : CameraClearFlags.Color;
}
```

也就是镜厅的唯一效果是**背景相机不擦颜色缓冲**（`Depth`），让上一帧没被覆盖的像素留在屏幕上 —— 这是**随时间累积**的错觉效果。
游戏里逐帧播放成立；工作台是随机访问的求值器，缓冲区里留的是"上一次显示过的画面"，于是变成

## 定格第一版静默失效：`magnitude` 被 NaN 分量污染（提交 `da5ba85`）

## [22:31] 真因：useMaskingDepth 的 "Enabled" 字符串被当成了 false
