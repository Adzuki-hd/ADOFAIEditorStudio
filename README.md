# ADOFAI Editor Studio

《冰与火之舞》的谱面编辑器工作台。叠在游戏原生编辑器之上，提供**不进游玩状态**的实时预览、时间轴浏览和事件参数编辑。

当前版本 **0.36.0**

---

## 它解决什么问题

原版编辑器里想看一段效果，只能按播放、看完、再退回来改。工作台把这层拆开：

- **拖时间轴就出画面** —— 不调原版的 `Play()`，不触发读秒、判定和游戏状态变化
- **一屏看全所有事件** —— 几百上千个事件块按时间装箱，纵向高度只等于「同时重叠的事件数」
- **改参数不用翻原生面板** —— 右侧参数栏由游戏自身的属性元数据生成

## 环境要求

| 项目 | 要求 |
|---|---|
| 游戏 | 《A Dance of Fire and Ice》Steam 版 |
| Mod 加载器 | Unity Mod Manager `0.32.5` |
| 其他依赖 | **无**（不需要 JALib，也不需要任何前置 mod） |

界面是 Unity 原生 uGUI，不依赖任何外部 GUI 库。

## 安装

把压缩包里的 `ADOFAIEditorStudio` 文件夹整个放进游戏的 `Mods` 目录：

```
<游戏目录>/Mods/ADOFAIEditorStudio/
├── Info.json
├── ADOFAIEditorStudio.dll     ← mod 本体
├── AesIcon.rgba               ← 左下角入口按钮图标
└── LICENSE
```

启动游戏，在 Unity Mod Manager 里确认 mod 已加载（显示「ADOFAI Editor Studio」）。

---

## 怎么打开

1. 进游戏的关卡编辑器，打开一张谱面
2. 点编辑器**左下角的圆形按钮**（贴在播放键右边）
3. 按 **Esc** 关闭

> 这个按钮是唯一入口，**没有键盘快捷键**。F8 试过，实测有用户的 F8 根本进不了 Unity（笔记本 F 键默认走媒体键，或被录屏 / 输入法 / 显卡 overlay 抢了全局热键）。

打开后默认是**只读**，要改东西先切到编辑模式。

## 自动更新

**启动时检查更新，发现新版自动下载替换。装好后需要你关掉游戏再打开一次。**

- 版本低于要求 → 自动下载 → 覆盖 → 提示你重开游戏
- 已是最新 → 什么都不做
- 读不到更新信息（断网、源不可用）→ 照常运行，只记一条日志

装好之后日志里会出现这一行：

```
[Update] 已装好 x.y.z。请关闭并重新打开游戏以生效。
```

更新走 GitHub，国内网络可能不稳。连不上不影响使用，但也不会自动升级 —— 那种情况请到群里手动下载最新包。

## 功能一览

| 模块 | 内容 |
|---|---|
| **预览** | 21 个求值域，覆盖轨道 / 镜头 / 装饰物 / 滤镜 / 粒子 / 行星 / 音效，数学对齐游戏本体 |
| **时间轴** | 按时间装箱、拖块改时间与时长、多选批量拖、复制剪切粘贴、格号跳转 |
| **参数栏** | 由游戏属性元数据生成，支持 12 类控件，多选批量改值 |
| **左栏** | 装饰物列表（可搜索 / 隐藏 / 锁定 / 删除）+ 媒体库（拖图即建装饰物）+ 六个谱面设置页 |
| **撤销** | 工作台自己的撤销栈，与 PACL2 共存 |
| **视图锁** | 一键锁定镜头位置与缩放 |

详细的逐项说明、快捷键全表、已知问题、尚未完成的部分，见 **[功能详解.md](功能详解.md)**。
