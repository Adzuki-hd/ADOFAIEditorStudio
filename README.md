# ADOFAI Editor Studio

《冰与火之舞》编辑器工作台 mod。在游戏关卡编辑器之上叠加一层工作台，提供**不进入游玩状态**的实时预览、时间轴浏览和事件参数编辑。

当前版本 **0.10.9**，处于**开发中**：预览、浏览与装饰物编辑功能可用（见「尚未完成」）。

## 环境要求

- 《A Dance of Fire and Ice》（Steam 版）
- Unity Mod Manager `0.32.5`
- 无其他依赖（不需要 JALib）

## 安装

把压缩包里的 `ADOFAIEditorStudio` 文件夹整个放进游戏的 `Mods` 目录：

```
<游戏目录>/Mods/ADOFAIEditorStudio/
├── Info.json
├── README.md
└── ADOFAIEditorStudio.dll
```

`Mods` 目录通常在：

```
<Steam 库>/steamapps/common/A Dance of Fire and Ice/Mods/
```

启动游戏，在 Unity Mod Manager 中确认 mod 已加载（显示「ADOFAI 编辑器工作台」）。

## 自动更新

**启动时会检查更新，发现新版就自动下载、替换。装好后需要你关掉游戏再打开一次。**

- 版本低于要求 → 自动下载 → 覆盖 → **提示你重开游戏**，重开后就是新版
- 已是最新 → 什么都不做
- **读不到更新信息（断网、源不可用）→ 照常运行**，只记一条日志

装好之后日志里会出现这一行，看到它就可以关掉重开了：

```
[Update] 已装好 x.y.z。请关闭并重新打开游戏以生效。
```

**为什么不自动重启**：试过五种重启方式，都会在真实环境下起出一个卡住的实例（游戏能进，但所有 mod 都不加载）。安装本身是可靠的，只有"重启"这一步不可靠，所以交给用户点两下。

更新走 GitHub，国内网络可能不稳。**连不上不影响使用**，但也不会自动升级 —— 那种情况请到群里手动下载最新包。

## 使用

1. 进入游戏的关卡编辑器，打开一张谱面
2. 按 **F8** 打开工作台
3. 按 **Esc** 关闭

工作台接管渲染：画面由 mod 自己的求值器逐帧计算，**不调用游戏原有的 `Play()`**，因此可以任意拖动时间轴而不会触发读秒、判定或游戏状态变化。

## 已实现

**预览**

- 独立的绝对时间求值器，覆盖 15 类事件域：轨道移动与轨道动画、镜头、轨道上色、装饰物、闪烁、泛光、自定义背景、屏幕平铺、屏幕滚动、镜像、震屏、滤镜、高级滤镜、粒子、行星（球）
- 行星预览：位置、旋转角度、角速度、红蓝配色、尾焰拖尾
- 效果数学对齐游戏本体，而非近似：每个域都对照反编译源码或实测数据校准过
- 拖动时间轴时逐帧求值；基准为绝对时间，不依赖拖动方向

**时间轴**

- 读取真实谱面事件，分为镜头、视效、装饰、音频、游戏、其他六类
- 按事件类型分色，同类型优先同水平线排布
- 缩放（`Ctrl + 加号/减号`、`Ctrl+滚轮`）、行高调整（`Alt + 加号/减号`、`Alt+滚轮`）
- 拖动顶部细条调整时间轴面板高度
- 滚轮纵向浏览，`Shift+滚轮`横向浏览，中键拖动平移
- 点击事件块选中，与游戏原生选择联动
- 面板高度变化时自动重排，事件标记数量与行高自适应
- 左侧为装饰物列表（见下）

**参数栏**

- 选中时间轴上的事件块后，右侧列出该事件的可编辑属性
- 参数表由**游戏自身的属性元数据**生成，不是手工维护的表，因此新事件类型无需改动代码即可显示
- 支持控件：开关、整数、浮点、文本、枚举、二维向量、颜色（色块 + 十六进制）
- 属性名跟随游戏语言（中文客户端显示中文）
- 装饰物事件顶部显示对应的装饰物图片
- 面板变窄时双输入框自动改为上下排列
- 输入框有可见光标与聚焦高亮

**装饰物编辑**

- 从左侧媒体区**拖动图片到画面**即可新建装饰物，跟随鼠标落点
- 拖动中调整：滚轮缩放、`Alt+滚轮`旋转、`Ctrl+滚轮`透明度、`Shift+滚轮`深度、`Ctrl+Shift+滚轮`平行（视差）
- 顶部状态栏实时显示当前调整值
- 松手在画面内保留；拖回左侧或松手在画面外取消
- 拖动已有装饰物改位置（写入当前帧关键帧）

**撤销 / 重做**

- `Ctrl+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做
- 覆盖：新建装饰物、删除装饰物、拖动装饰物、参数栏改值、装饰物显隐与锁定
- 工作台维护自己的撤销栈，**与 PACL2 共存**；未接管的操作回退到游戏原生撤销

**视图锁**

- 时间轴上的锁形按钮：一键同时锁定**镜头位置**与**缩放**
- 锁定后拖动画面或滚轮缩放会立即弹回谱面原本的取景
- 状态随设置保存

**性能**

- 关闭工作台时不影响游戏
- 大谱面下跳过"全透明装饰物"的逐帧写入；在 1253 个装饰物的谱面上从 20 帧提升到 70 帧以上

**媒体区**

- 自动索引谱面目录（含子目录）内的 PNG/JPG/JPEG/GIF，六列缩略图网格
- **搜索**与**刷新**，按修改时间倒序（新图在前）
- 从媒体格直接拖到画面即可新建装饰物
- 不写任何附属文件；索引每次扫盘得出

**装饰物列表**

- 时间轴左侧列出当前谱面所有装饰物，点击选中（右侧参数栏跟随）
- 每行显示图片文件名、tag、类型图标，以及**隐藏 / 锁定 / 删除**三个操作
- 可按名字、tag、类型、所在格搜索（支持 `tag:` / `type:` / `floor:` 前缀）
- 顶部四个按钮新建图片 / 文本 / 粒子 / 对象装饰物
- 「全部隐藏 / 全部锁定」是**临时查看**开关，不写进谱面，关掉工作台自动复原

**其他**

- 每格打拍器音量（`SetHitsound` / `SetHoldSound`）按谱面取值播放

## 尚未完成

- **参数栏仅覆盖部分属性类型**：Tile、FloatPair、Vector2Range、FilterProperties、列表等目前显示为「暂不支持」
- **编辑功能不完整**：只有装饰物相关（新建 / 拖动 / 改值）和参数栏改值；新增其它类型事件、拖动改时间、批量编辑尚未支持
- **`EndSession` 状态还原不完整**：部分域的跨会话状态尚未还原
- **PlaySound / AddObject / SetObject** 事件未接入（`ffxPlaySound` 等组件与打拍器同在那道 `paused` 闸之后，目前未补建）
- **`maskingTarget` 未实现**：装饰物遮罩的"指定遮罩源"属性未处理（`maskingType` 与遮罩深度已实现）
- **复杂格子未建模**：Freeroam、Hold、ExtraBeats、非双行星格子会跳过预览并记录日志
- **颜色选择器**：目前只有色块和十六进制输入，没有可视化取色面板

## 已知问题

- 关闭工作台后，游戏原生编辑器的事件特效可能滞后一拍（求值器直接读取事件数据，不驱动原生特效）。进入游戏播放时会自动重建
- ShakeScreen、粒子等域在极端参数下未做充分回归
- 与 PACL2 共存时，工作台内的撤销只覆盖工作台自己记录的操作；原生面板里做的改动请继续用游戏原有的撤销路径

**版本更新记录**

- **0.10.8** —— 用于验证「装好后提示重开」的更新流程（无功能改动）
- **0.10.7** —— 自动更新不再自动重启：装好后提示**关闭并重新打开游戏**。五种重启方式都会在真实环境下起出卡住的实例（游戏能进但所有 mod 不加载），而安装本身可靠，所以把最后一步交给用户
- **0.10.6** —— 重启助手从 PowerShell 换成批处理（cmd.exe）：由游戏进程派生的 PowerShell 起出来的实例会卡在启动阶段且 UMM 不加载，换成最朴素的 `cmd.exe` + `.bat`
- **0.10.5** —— 更新重启的等待从 1.5 秒加到 6 秒：游戏走`Application.Quit()` 优雅退出，其清理（GPU / 文件句柄）比被强杀慢得多，1.5 秒后起的实例会卡在 `Shader.WarmupAllShaders()`、UMM 完全不加载
- **0.10.4** —— 修复自动更新重启后 UMM 不加载：启动重启助手时误用 `UseShellExecute = false`，子进程继承了 Unity 的句柄/控制台环境，被它再启动的游戏起不来（Player.log 里连一行 `[Manager]` 都没有）。改为 `true`
- **0.10.3** —— 自动更新的重启改为**等本进程真正退出后再起新实例**（`Wait-Process -Id <自己的pid>`）：之前用的是固定延迟，但旧进程还没退新进程就起来了，两个实例重叠，UMM 解析到一半就退出，表现为「重启后 UMM 不加载」
- **0.10.2** —— 自动更新的重启改为最直接的 `Process.Start(exe)`，不再经 cmd（那条链上的 `timeout` / `ping` / `start` 在本项目的调用环境下都不可靠）
- **0.10.1** —— 修复自动更新重启后 UMM 不加载：重启的延迟原用 `timeout /t 2`，但 `UseShellExecute=false` 时 stdin 被重定向，Windows 的 `timeout` 会立刻报错退出（实测耗时 0 秒），导致新实例在旧实例未退完时就启动。改用 `ping` 做延迟（实测稳定 2 秒）
- **0.10.0** —— 修复自动更新重启后 UMM 全线失效：不再用 `steam://launch/<appid>`（实测它起的实例会卡在 shader warmup 三分钟后消失，UMM 一行日志都不写），改回直接起 exe；同时在 Steam 未运行时先把它唤醒
- **0.9.9** —— 修复自动更新下载失败：显式把 TLS 拉到 1.2+（Mono 默认可能还在 TLS 1.0，jsDelivr 只收 1.2+，握手被掐断表现为 SecureChannelFailure）；并为主下载地址配上 raw.githubusercontent.com 备用镜像
